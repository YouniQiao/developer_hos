# OH_MIDIDeviceStruct

```
typedef struct OH_MIDIDeviceStruct OH_MIDIDevice
```

#### 概述

OH_MIDIDevice用于声明和表示MIDI设备，提供对MIDI设备的标识与引用能力，适用于需要在应用中对MIDI设备进行操作的场景。
