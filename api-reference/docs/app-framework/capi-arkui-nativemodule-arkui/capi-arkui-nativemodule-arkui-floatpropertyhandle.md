# ArkUI_FloatPropertyHandle

```
typedef struct ArkUI_FloatProperty* ArkUI_FloatPropertyHandle
```

#### 概述

定义ArkUI原生浮点渲染属性指针，用于创建、传递并管理目标内容修改器上的浮点属性。

起始版本： 20
