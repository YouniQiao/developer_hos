# ArkUI_CustomSpanMetrics

```
typedef struct ArkUI_CustomSpanMetrics ArkUI_CustomSpanMetrics
```

#### 概述

自定义绘制Span的度量指标，用于设置组件的宽高等布局信息。适用于富文本编辑器、聊天应用等场景的图文混排。

起始版本： 12

相关模块： [ArkUI_NativeModule](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-arkui-nativemodule)

所在头文件： [custom_span.h](https://developer.huawei.com/consumer/cn/doc/harmonyos-references/capi-custom-span-h)
