# ArkUI_StyledString_Descriptor

```
typedef struct ArkUI_StyledString_Descriptor ArkUI_StyledString_Descriptor
```

#### 概述

定义文本组件支持的属性字符串的数据对象，支持对文本内容进行样式设置与管理，适用于需要富文本展示、样式定制等场景。

起始版本： 14
