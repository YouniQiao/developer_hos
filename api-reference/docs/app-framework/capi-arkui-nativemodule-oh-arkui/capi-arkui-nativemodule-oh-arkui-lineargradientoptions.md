# OH_ArkUI_LinearGradientOptions

```
typedef struct OH_ArkUI_LinearGradientOptions OH_ArkUI_LinearGradientOptions
```

#### 概述

定义线性渐变效果选项，用于描述UI组件的线性颜色渐变配置，支持设置渐变方向、角度和颜色配置，帮助开发者实现灵活的线性渐变效果，提升UI视觉呈现能力，适用于需要为组件应用线性渐变样式的场景。

起始版本： 26.0.0
